# RR Clinic — план: Hero + Navbar (desktop)

Старт: вторник 2026-10-20. Стек: статика HTML/CSS/vanilla JS (ES modules), canvas/WebGL для частиц и света.

## 1. Scope и допущения

**In:** Hero (десктоп), фоновые эффекты (частицы, мерцание света), карусель фона, карточка врача с кейсами (видео по hover), before/after слайдер, анимация появления текста, меню выбора хирурга, CTA со световой анимацией, navbar (expanded -> island), reduced-motion, QA.

**Out:** мобильная/планшетная версия (<1280px), остальные секции лендинга, CMS/админка, формы и бэкенд-логика записи, мультиязычность (RU/KZ) сверх заготовки в data-схеме.

**Later:** "плашка" (баннер; после получения дизайна), реальные видео кейсов, аналитика, мобильная версия.

**Допущения:**
- Только desktop >= 1280px; ниже показываем статичный fallback без эффектов.
- Futura PT платный: нужны файлы/лицензия от клиента; пока fallback `"Jost", "Century Gothic", system-ui` (подключить локально, без CDN).
- Реальных видео кейсов нет: постер + placeholder-ролики (короткие mp4/webm 3-5 с).
- Референс покадровой анимации и Figma — источник правды по motion; расхождения решает дизайнер.
- Ответ на вопрос клиента: фон технически реализуем (частицы и свет на canvas/WebGL, карусель и hover — CSS+JS).

## 2. Чек-лист требований

| ID | Требование | Владелец | Критерии приёмки (проверяемо) |
|---|---|---|---|
| H-01 | Медленные частицы | FE-1 | Canvas/WebGL за контентом; скорость дрейфа низкая (по спеке); <= 2 мс/кадр на M1, 60 fps в Performance trace; pointer-events:none; ресайз без артефактов; DPR ограничен 2 |
| H-02 | Мерцание фонового света | FE-1 | Плавная пульсация/сдвиг света без резких скачков яркости (нет вспышек > 1 Гц); не нагружает больше +1 мс/кадр; совпадает с референсом по цвету |
| H-03 | Карусель фона слева направо | FE-2 | Непрерывное движение слева направо, бесшовный loop (нет скачка/пустоты за 5 мин); скорость по спеке; transform/GPU-слой, без layout-thrash |
| H-04 | Пауза карусели при hover | FE-2 | Остановка <= 300 мс после pointerenter с плавным замедлением; возобновление с той же позиции на pointerleave |
| H-05 | Карточка врача выезжает снизу | FE-2 | При hover на слайде карточка (фото + кейсы) выезжает снизу за 400-600 мс, easing по спеке; на leave возвращается; нет мерцания при быстром наведении/уходе |
| H-06 | Кейсы = видео, играют по hover | FE-2 | `<video muted playsinline preload="metadata" poster>`; play на hover, pause + currentTime=0 на leave; одновременно играет <= 1 видео; play() обёрнут в catch (autoplay-политика) |
| H-07 | Before/After слайдер | FE-2 | Перетаскивание мышью (pointer events + capture) и клавишами Left/Right (шаг 5%, Shift = 10%); role="slider", aria-valuenow; ручка не выходит за границы; отпускание вне элемента не "залипает" |
| H-08 | Карточка за заголовком поднимается над текстом | FE-2 (+FE-3) | Токены z-index в tokens.css; на hover z-index карточки > z-index заголовка; на leave возвращается без визуального скачка; заголовок не перехватывает hover |
| H-09 | Плавное появление текста | FE-3 | Stagger-reveal заголовка/подзаголовка/CTA при загрузке, 600-900 мс, только transform+opacity; повтор не происходит при ресайзе; при reduced-motion — мгновенно |
| H-10 | Меню выбора хирурга | FE-3 | Список врачей из hero.json; выбор подсвечивает активного и вызывает событие `surgeon:select` (карусель реагирует); доступно с клавиатуры (Tab/Enter/стрелки), focus-visible; поведение уточняется (вопрос клиенту) |
| H-11 | CTA со световой анимацией | FE-3 | Свет скользит/пульсирует по кнопке на hover и (мягко) в idle; без layout shift; фокус-состояние различимо; цели ссылок из конфига |
| H-12 | Покадровая анимация-референс | Дизайнер + FE-3 | Спека кадров/таймингов в design-spec.md; реализация совпадает с референсом по таймингам +-50 мс (проверка наложением записи) |
| H-13 | prefers-reduced-motion | Все FE, QA | При включении: частицы, мерцание, движение карусели, reveal и световые CTA отключены/статичны; контент и hover-карточка остаются доступными (без анимации) |
| H-14 | Данные героя | Backend | hero.json валиден по схеме (docs/data-schema.md); hero-data.js отдаёт врачей, кейсы, постеры, видео; картинки через optimize-images.sh (webp/avif, <= 300 КБ на слайд) |
| N-01 | Navbar раскрыт на первом экране | FE-3 | При scrollY <= 80 — полная панель (лого, пункты, CTA) по Figma |
| N-02 | Сворачивание в "остров" | FE-3 | После scrollY > 80 — центрированный остров с плавной анимацией 300-500 мс; hysteresis (разворот при <= 80, без дребезга); scroll-обработчик через rAF/IntersectionObserver |
| N-03 | Возврат при скролле наверх | FE-3 | При scrollY <= 80 навбар снова раскрыт; нет прыжков контента (position: fixed/sticky, высота зарезервирована) |
| N-04 | Доступность навбара | FE-3, QA | Клавиатурная навигация в обоих состояниях; aria-label; контраст >= 4.5:1; остров не перекрывает фокус |
| N-05 | Референс острова | Дизайнер | После получения ссылки на лендинг — зафиксировать тайминги/размеры в design-spec.md |
| G-01 | Каркас и токены | Lead | index.html, tokens.css (цвета, z-index, easing, тайминги), base.css, main.js подключает модули; нет конфликтов файлов между ролями |
| G-02 | Производительность | QA | 60 fps (p95 кадра <= 16.7 мс) на M1 в Chrome и Safari при hover-сценариях; LCP <= 2.5 с; 0 ошибок в консоли; вес первого экрана <= 2 МБ без видео |
| G-03 | Сверка с Figma | QA | Pixel-сверка на 1280/1440/1920: расхождения <= 2 px по отступам, шрифтам, цветам |

## 4. Риски и меры

| Риск | Мера |
|---|---|
| Нагрузка WebGL + много видео | Один общий rAF-цикл; лимит частиц (адаптивно по FPS); DPR <= 2; пауза эффектов при скрытой вкладке и вне viewport; видео preload="metadata", одно активное, постеры; деградация (меньше частиц) при просадке < 50 fps |
| Autoplay-политики браузеров | Только muted+playsinline; play() с catch; fallback — постер; запуск по hover (user gesture не обязателен для muted, но обрабатываем отказ) |
| Лицензия Futura PT | Запросить файлы/лицензию (webfont, woff2); до этого — fallback-шрифт с близкими метриками, font-display: swap; не использовать нелицензионные копии |
| Hover-only взаимодействия и доступность | Дублировать на focus (Tab) и Enter/Space; кейсы доступны с клавиатуры; видео не критичны для контента; aria-label; reduced-motion |
| Тяжёлые изображения | optimize-images.sh: webp/avif, размеры под 1x/2x, бюджет <= 300 КБ на слайд; lazy для не-первого экрана |
| Конфликты правок между разработчиками | Жёсткое владение файлами (см. раздел команды); общие токены только через Lead; интеграция в конце каждого дня |
| Расхождение с референсом (нет ссылки/покадровой анимации) | Запросить материалы сегодня; дизайнер фиксирует тайминги в спеке; временные значения помечены TODO |
| Safari/WebGL отличия | Проверка Chrome + Safari + Firefox; fallback на Canvas2D для частиц |
